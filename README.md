# Vijust
### Visual + Adjust
Vijustはウェブサイトの文章の視認性の向上を目的とした色覚補助システムです

### *マークダウンの書き方教えてくださいTT*

# How to Install Vijust

詳しくは[こちら](https://exemate.co.jp/how-to-install-a-self-made-chrome-extension/)(exe_mate 自作したchrome拡張機能のインストール方法 2024/10/12)

1. このリポジトリをダウンロードする
2. [Chrome Extensions](chrome://extensions/)にアクセスしデベロッパーモードをオンにしてタブを更新する。（Google Chrome限定）
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、「Vijust」をアップロードし有効化する


# How to Use Vijust
1. Google Chromeのツールバーから拡張機能アイコンをクリックし、Vijustの項目をクリックする。
2. 表示されたポップアップから、「文章を選択」ボタンを押し、点線で囲われた文章をクリックする。
3. 選択した文章の文字色を、プレビューをもとに色を変更する
4. 選択した文章に縁取りをつけることもできる。

## Backgrounds
以下自論文から引用
>　ウェブサイトの色表現によっては,情報の正確な取得が困難となる場合がある。遺伝的な要因により,一人一人に色の見え方が異なり,その種類には正常な色覚である3色型色覚だけでなく,赤と緑の判別が困難な2色型第1・2色覚や赤要素のみが受け取れる赤錐体一色型色覚などが含まれる。このような色覚特性を持つ人は,日本国内には約500万人以上いると推定されている。そのため,個々の色覚多様性に配慮されていない色表現では情報を受け取りづらい場合があるのだ。

>　色覚多様性による情報収集の困難さを克服するため,ウェブページ上の色表現を任意に変更できるシステムの開発を行った。ウェブページ上の色表現は,HTMLおよびCSSを編集することで変更可能であり,さらにJavaScriptを用いることで動的に色表現を変更するシステムを構築することができる。このシステムにより,個々の色覚多様性に対応した色に変更することで,より見やすいウェブページを実現することを目指した。
